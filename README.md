# Smart Zombies V3 — Forge 26.3

Alvo: Minecraft 26.3 + Forge 26.3-66.0.9 + Java 25.

Recursos planejados no comportamento:
- alvo apenas Survival/Adventure;
- memória de alvo;
- coleta de drops;
- inventário interno;
- ferramentas e armaduras;
- mineração com progresso e cooldown;
- coleta de madeira;
- crafting básico;
- uso/armazenamento de blocos;
- construção para vencer obstáculos;
- pontes e torres simples;
- navegação e combate vanilla.

## Compilar no GitHub Actions
O workflow `.github/workflows/build.yml` já usa Java 25 e Forge 26.3-66.0.9.
Depois do build, baixe o artefato `SmartZombies-Forge26.3-JAR`.
